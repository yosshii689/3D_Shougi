# 軍棋 — 赤と青の戦場

赤軍と青軍の小さな立体部隊で戦う、オフラインの3D将棋です。

## 起動

このフォルダーの **index.html をダブルクリック**してください。Chrome / Microsoft Edge など、WebGLに対応するブラウザで遊べます。

インストール、インターネット接続、ローカルサーバーは不要です。別の場所に移すときは、`vendor` を含むフォルダー全体をコピーしてください。

最初にタイトル画面が開きます。「対局・設定」で対戦モード・CPUの強さ・音を設定し、「対局を始める」で盤面へ進みます。「戦いの記録」タブで現在の対局の棋譜を閲覧できます。保存済みの対局がある場合は「対局に戻る」で再開します。

対局中は盤面がウィンドウ全体に広がります。右上の「全画面表示」でブラウザの枠も隠せます。「タイトルへ」で設定・棋譜に戻れます。タイトル画面を開いている間はCPUも停止します。

## 操作

- 自軍のユニットをクリック → 緑色に光るマスをクリックして移動。敵のいる移動先は赤色に光ります。
- 持ち駒は盤の左右にある立体の駒台から、兵をクリックして選び、光るマスへ再出撃できます。捕獲した兵は成りを解除し、自軍カラーで並びます。
- 敵を取るときだけ、盤面上の実際の2体へ同じカメラが滑らかに移動して接近します。周囲の盤面や駒もそのまま見えます。突撃・斬撃、光の軌跡、衝撃波のあと、捕虜が自軍色になって駒台へ移動し、カメラが元の視点に戻ります。全体で約4.6秒です。
- 敵陣3段で成れるときは選択画面が開きます。行き所がなくなる移動は自動で成ります。
- 右ボタンを押しながらマウスを動かして視点回転、ホイールで拡大・縮小。「俯瞰」で上空から見渡せます。盤面の右クリックメニューは表示されません。タッチ操作ではドラッグで回転します。
- 「駒名」で駒の文字表示を切り替え。「音 ON」で効果音を有効にできます。
- Escで選択解除。「待った」で戻す。「投了」で敗北を認めて終了します。

## 対戦

**CPU対戦**では、あなたが赤軍（先手）、CPUが青軍（後手）です。「入門」と、相手の反撃も評価する「標準」を選択できます。CPUは初心者向けの簡易思考です。

**2人対戦**では、同じ画面で赤軍・青軍を交互に操作します。対戦モードは途中でも切り替えられます。

CPU対戦の「待った」は、通常あなたの手とCPUの応手をまとめて戻します。CPUが考慮中なら直前のあなたの手だけを戻します。

ブラウザで保存が許可されている場合、対局・棋譜・設定を自動保存します。同じブラウザで同じHTMLを開くと再開します。ブラウザ設定やプライベートモード、ファイルの移動によって保存・復帰できない場合があります。

## 部隊

| 駒 | 立体ユニット | 演出 |
|---|---|---|
| 歩 | 足軽 | 足を動かして進軍 |
| 香 | 長槍兵 | 前傾して高速突進 |
| 桂 | 軍馬に乗った騎兵 | 弧を描いてジャンプ |
| 銀 | 銀鎧の隊長 | 素早い進軍・斬撃 |
| 金 | 金鎧の重装武将 | 重厚な進軍 |
| 王 | 王冠とマントを着けた王 | ゆっくりと威厳ある進軍 |
| 角 | 大鳥に乗った遊撃将 | 羽ばたきながら上昇・急降下 |
| 飛 | 四輪戦車の将軍 | 車輪を回して突撃 |

成ると金色の装備とリングが加わります。捕獲された駒は成りを解除して自軍の持ち駒となり、自軍カラーで再出撃します。

## ルール対応

通常の移動、成り・不成・強制成り、持ち駒、王手・詰み、二歩、打ち歩詰め、行き所のない駒、自玉への王手を残す手の禁止に対応しています。王を実際に捕獲する前に、詰みで決着します。

同一の盤面・持ち駒・手番が4回現れる千日手は引き分け扱いです。連続王手による千日手は王手を続けた側の負けです。指し直す場合は「新しい対局」を選んでください。

**未対応：入玉宣言、持将棋の点数判定・500手判定、対局時計、オンライン対戦、棋譜の外部ファイル入出力。**

ルール確認先：日本将棋連盟「対局規則」 https://www.shogi.or.jp/match/taikyoku_rules/ 、 「将棋のルールに関するご質問」 https://www.shogi.or.jp/faq/rules/

## ファイル

- `index.html`：ゲームの入口
- `style.css`：操作画面・画面サイズへの対応
- `fullscreen.css`：画面いっぱいの盤面・タイトル画面のレイアウト
- `screen.js`：タイトル・対局の切り替え、棋譜タブ、全画面表示
- `engine.js`：将棋ルール・CPU思考
- `game.js`：3Dモデル・アニメーション・操作・保存
- `capture.js`：盤上を移動する戦闘カメラ・捕獲演出・立体の駒台
- `vendor/three.min.js`：同梱のThree.js r128（MITライセンス）
- `vendor/LICENSE-three.txt`：Three.jsのライセンス
- `screenshot.png`：PC画面のプレビュー
- `engine.test.cjs`：Node.jsで実行できるルールテスト
- `browser-test.cjs`：開発用ブラウザ操作テスト（隣の `Playwright/node_modules/playwright` を利用）
- `capture.test.cjs`：全8種の捕獲、両軍の色変更、駒台からの選択、カメラ復帰、演出中のリセットを確認するテスト

3Dモデルはコードで組み立てたオリジナルのローポリゴンモデルです。外部モデル、画像、フォントのダウンロードは行いません。

## 開発用の確認

このフォルダーで `node engine.test.cjs` を実行すると、移動、成り、捕獲、禁じ手、詰み、千日手、CPUの80手対戦を確認します。ブラウザテストは `node browser-test.cjs` です。通常のプレイにNode.jsは不要です。

3D画面が表示されない場合は、Chrome / Edgeのグラフィックアクセラレーション設定を確認してください。
